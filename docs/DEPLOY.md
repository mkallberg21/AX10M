# Deploying the AX10M demo

One deployment (the Next.js dashboard) serves everything: the live demo, the pitch
page, and the downloadable signed statement. No processor credentials are required —
the demo runs entirely on data generated by the Phase-1 world model.

## What gets served

| Path | What |
|---|---|
| `/` | the shadow-mode demo dashboard (projected opportunity + illustrative active statement) |
| `/pitch.html` | the pitch page (leads with the CFO-reconcilable signed statement) |
| `/uplift-statement.json` | the Ed25519-signed Uplift Statement |
| `/uplift-statement.csv` | recovered transactions to tie to a Stripe payout |
| `/uplift-ledger.json` | the hash-chained ledger |
| `/ax10m-demo-pubkey.pem` | the public key to verify the signature |

## Regenerate the demo data (optional)

The demo artifacts are committed, so `dev` and a deploy work as-is. To regenerate from
the world model:

```bash
corepack pnpm -r build                         # build the workspace (incl. @ax10m/backtest)
corepack pnpm --filter @ax10m/dashboard gen-demo
```

This rewrites `app/demo-data.json` and the four `public/` artifacts. Because it uses the
same generator as the backtest, the demo can never show a number the backtest denies —
today that means the statement honestly bills **$0** (the engine does not yet beat the
baseline).

## Run locally (no credentials)

```bash
corepack pnpm --filter @ax10m/dashboard dev    # http://localhost:3000
```

## Deploy to Vercel

The dashboard is a standard Next.js 14 app.

- **Root directory:** `apps/dashboard`
- **Install command:** `corepack pnpm install` (run from the repo root; it's a pnpm workspace)
- **Build command:** `corepack pnpm --filter @ax10m/dashboard... build`
- **Output:** `.next` (Vercel auto-detects Next.js)

No environment variables are needed for the demo. Once deployed, update the pitch page's
"See the live demo" link if your dashboard lives on a different origin than the pitch.

## Deploy the pitch page to GitHub Pages (alternative)

`docs/pitch.html` (and its copy at `apps/dashboard/public/pitch.html`) is a single
self-contained static file — inline CSS/JS, no build step. To host it on GitHub Pages,
publish `docs/` (or copy `pitch.html` to the Pages branch) and point the "live demo" and
"backtest" links at your deployed URLs.

## Verify the signed statement (for a skeptical CFO)

Anyone can verify the statement with only the public inputs — no trust in AX10M:

```bash
corepack pnpm --filter @ax10m/attribution build   # build the verifier once
node scripts/verify-statement.mjs \
  apps/dashboard/public/uplift-statement.json \
  apps/dashboard/public/ax10m-demo-pubkey.pem \
  apps/dashboard/public/uplift-ledger.json
```

Expected output: PASS on the statement hash, the Ed25519 signature, and the
hash-chained ledger — and `fee billed: $0.00 (billable=false)`, the honest result.
